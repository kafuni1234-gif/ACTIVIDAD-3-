# ACTIVIDAD-3-

Investigación de 30 funciones básicas de Python



1\. Descripción del proyecto



El presente proyecto consiste en investigar, documentar y desarrollar ejemplos prácticos de treinta funciones básicas del lenguaje de programación Python. Se busca comprender el funcionamiento de cada función, su sintaxis, sus principales características y sus aplicaciones mediante ejercicios de programación.



El desarrollo del proyecto se realiza utilizando Jupyter Notebook, a través de Google Colab, y GitHub como plataforma para almacenar el código, organizar los avances y facilitar el trabajo colaborativo entre los integrantes del grupo.



2\. Objetivos



Objetivo general



Investigar y aplicar treinta funciones básicas de Python mediante explicaciones teóricas y ejemplos prácticos desarrollados en Jupyter Notebook, fortaleciendo los conocimientos fundamentales de programación.



Objetivos específicos



Identificar treinta funciones incorporadas de Python y comprender su utilidad.



Explicar la sintaxis y los parámetros principales de cada función.



Desarrollar ejemplos prácticos que permitan observar su funcionamiento.



Ejecutar y verificar los códigos elaborados en Jupyter Notebook.



Fomentar el trabajo colaborativo mediante el uso de GitHub y el registro de avances a través de commits.

6\. Metodología de trabajo



El proyecto se desarrolla de manera colaborativa, distribuyendo las funciones entre los integrantes del grupo para facilitar la investigación y programación.



Cada participante se encarga de documentar y desarrollar los ejemplos correspondientes a su sección. Posteriormente, los avances se incorporan al repositorio compartido de GitHub mediante commits, permitiendo llevar un registro de las modificaciones y contribuciones realizadas durante el desarrollo de la actividad.



7\. Contenido académico



Se investigan treinta funciones incorporadas de Python, entre ellas:



Funciones de entrada y salida de información.



Funciones de conversión y manipulación de tipos de datos.



Funciones matemáticas y numéricas.



Funciones para trabajar con listas, tuplas, conjuntos y diccionarios.



Funciones para recorrer, filtrar y organizar colecciones.



Funciones para consultar y verificar información.



Cada función cuenta con su respectiva explicación y ejemplos prácticos.



8\. Evidencia del trabajo colaborativo



El historial de commits del repositorio permite consultar los avances realizados durante el proyecto, identificar las contribuciones de cada integrante y observar la evolución del trabajo.
